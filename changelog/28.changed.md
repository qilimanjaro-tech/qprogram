`MeasurementSample.raw` now defaults to an empty `(0, 2)` array, so a measurement model with no ADC to simulate no longer has to invent a filler trace. A measurement that requests `MeasurementField.RAW` checks the trace's shape against the model's `raw_samples` and raises a `ValueError` naming the measurement, the shape received, and the shape expected. Previously a mismatched trace either died with a bare numpy broadcast error that named nothing, or — for a `(2,)` or `(1, 2)` trace — was silently broadcast across every time sample and returned a wrong result with no error at all. The check goes through `numpy.shape`, so a nested list or tuple remains a valid trace.
