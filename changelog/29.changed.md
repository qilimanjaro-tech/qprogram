The example pages now carry the figures their programs produce. Each one is rendered by building the page's own program, running it on the reference platform, and writing the result to `docs/assets/plots/`, so a plot cannot drift from the code printed above it. Every figure is written once per site theme and the page picks the one built for the surface being read on, so the dark variant is its own render on the dark surface rather than a light figure behind a filter.
