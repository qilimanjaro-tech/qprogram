`PlatformProtocol.execute` takes `debug=True`, which asks the platform to also keep, for each measurement, whatever it measured before turning it into fields, such as an instrument's acquisition record. The platform passes it as an `xarray.Dataset` to `QProgramResult.append_measurement(..., debug=...)`, the new `MeasurementResult.debug` holds it as passed, and `QProgramResult.get_debug` reads it with the same lookup as `get`, raising `KeyError` when the run kept none. The reference platform simulates and has nothing to keep, so `ReferencePlatform.execute(..., debug=True)` raises an `ExecutionWarning`.
