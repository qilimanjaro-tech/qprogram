# Examples

End-to-end programs that you can copy, paste, and adapt. Each example builds
the program, shows its `.qp` form, and points to the relevant guide pages.

| Example                                                  | What it shows                                                      |
|----------------------------------------------------------|--------------------------------------------------------------------|
| [Rabi oscillation](rabi.md)                              | The smallest interesting QProgram: average, sweep, measure.        |
| [CZ chevron](cz-chevron.md)                              | Two-qubit gate calibration with nested sweeps and flux pulses.     |

If you would rather start from the API, jump to
[Operations](../guide/operations.md) or the
[API reference](../reference/api-qprogram.md).
